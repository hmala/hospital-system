# Workflow: Deploy to Hostinger

When `/deploy` is invoked:
1. Immediately launch the interactive batch script in a new Command Prompt window:
   `cmd.exe /c start deploy_hostinger.bat`
2. Confirm to the user that the Hostinger Deploy interactive window is open on their screen ready for them to choose options and type passwords.
